Rows 81-140 (added in message 3) cover the three newly-onboarded providers — Kubernetes, GitHub, GitLab — across the same 20 duplication categories. Per the explicit instruction not to touch a provider's own depth-QA/legacy test files in the same milestone it is onboarded, every framework-superseded category for these three providers is marked `Defer to message 4`, not deleted — matching the precedent set for Okta/Entra in message 2.
